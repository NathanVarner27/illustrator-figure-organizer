# Naming Standard

Use semantic names rather than Illustrator object types.

Good:

```text
03.04 — LEADER LINES
04.05 — GENRE
05.03 — HYBRID / BOUNDARY EXPLANATION
07.01 — SCOPE BOUNDARY TAKEAWAY
```

Avoid:

```text
Group
Path
Rectangle
Text
Layer 1
Icon 4
```

Recommended hierarchy:

```text
Top-level layer
    Semantic subgroup
        Artwork objects
```

Reserve `.99` for unresolved material, such as `03.99 — REVIEW / UNCLASSIFIED`.

For repository filenames, use stable names such as `figure-batch-organizer.jsx` and use Git tags/releases for versions.
